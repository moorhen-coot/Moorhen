Working with the MoorhenInstance

Once the <moorhen-web-component> element is ready, getMoorhenInstance() gives you a MoorhenInstance. That object is the whole programmatic API: loading data, moving the camera, managing representations, reading the store. This guide is shared by the plain-page and React flows, because the API is identical in both.

Prerequisite: the examples assume you already hold a moorhenInstance variable. See Setting up the WebComponent for a plain page, or Using the WebComponent in React for React. In a plain page these calls run directly; in React you keep them in effects or event handlers (see the React guide), but the API calls are the same.

The core API groups

Most of the API is grouped behind getters that each return an object of related methods. The API Reference documents every one of them:

Group What it does
files Load structures and maps from URLs, File/FileList objects, PDB/CIF strings or SMILES. Returns a LoadFilesResult per file.
getMoleculeList(), getMapList() Inspect what is loaded. Use getMolecule(uid) / getMap(uid) for a single object.
representation Create, edit, delete and style representations (ribbons, bonds, surfaces…). See also MoleculeRepresentation.
sceneSettings Scene-wide settings: background colour, ambient light, axes, perspective, zoom, origin, etc.
centerOnResidue(), centerOnAtom(), centerOnCoordinate() Move the camera to a residue, an atom or a coordinate.
newAtomHoveredCallback(), newMoleculeChangedCallback(), subscribeToStore() React to events: atom hover, molecule changes and store updates. See Callbacks and subscriptions.
session Restore a previously saved session.
execWhenReady(), isReady() Run code once Coot is initialised, or check readiness.
menuSystem Add your own main-menu entries and submenus. See Adding custom menus.
Other groups generalOptions, globalUI, mapContourSettings, mouseSettings, refinementSettings, backupSettings, modals, … all documented on the MoorhenInstance page.

Loading structures and maps

Molecules and maps are loaded through moorhenInstance.files.loadFiles(). It accepts one or more URLs (or Files, strings, URLs…) and returns a result per file telling you what was loaded and how to refer to it: 

interface LoadFilesResult {
    type: "molecule" | "map";
    uniqueID: string;   // use this to refer to the molecule/map later
    molNo: number;
    fileName: string;
}

The example below fetches the structure and the two maps of the PDB entry 7AVK straight from PDBe, then keeps the molecule’s uniqueID: 

const PDBe_FILES = "https://www.ebi.ac.uk/pdbe/entry-files";

const results = await moorhenInstance.files.loadFiles([
    `${PDBe_FILES}/7avk.cif`,           // coordinates
    `${PDBe_FILES}/7avk.ccp4`,          // 2Fo-Fc map
    `${PDBe_FILES}/7avk_diff.ccp4`,     // difference map
]);

const moleculeUid = results.find((item) => item.type === "molecule")?.uniqueID;

Keep the molecule’s uniqueID around: it is the stable handle you pass to most other API calls (centring, representations, validation, …). You can also ask the instance for the loaded molecules at any time with moorhenInstance.getMoleculeList() (or getMolecule(uniqueID)).

Creating a representation

Representations are created through moorhenInstance.representation, using a molecule’s unique ID: 

const moleculeUid = moorhenInstance.getMoleculeList()[0].uniqueId;

const repUid = await moorhenInstance.representation.create(moleculeUid, {
    representationStyle: "CAs",
    colourMode: "b-factor",
});

// Later: change it, then remove it.
await moorhenInstance.representation.edit(repUid, { colourMode: "secondary-structure" });
await moorhenInstance.representation.delete(repUid);

API tip: the full parameter list (styles, colour modes, bond options, residue-environment options…) is in the representation section of the API page, and the object itself is MoleculeRepresentation.

Controlling the view

Once a structure is loaded you can drive the camera. To centre on a specific residue, use centerOnResidue(chain, residueNumber, moleculeUniqueId): 

moorhenInstance.centerOnResidue("A", 1231, moleculeUid);

Scene-wide settings live under moorhenInstance.sceneSettings. These include background colour, ambient light, axes and perspective. For example, to set a light blue background (RGB values from 0 to 1, alpha 255): 

moorhenInstance.sceneSettings.setBackgroundColor([0.85, 0.9, 1.0, 255]);

Matching your page theme

A nice touch is to let the viewport follow the light/dark theme of your page. Keep the theme state wherever it already lives, pick a background colour per theme, and push it into Moorhen once at startup and again on every change: 

type Theme = "light" | "dark";

// RGB from 0 to 1, alpha from 0 to 255.
const BACKGROUNDS: Record<Theme, [number, number, number, number]> = {
    light: [1, 1, 1, 255],
    dark: [27 / 255, 30 / 255, 34 / 255, 255], // #1b1e22
};

function applyTheme(theme: Theme) {
    moorhenInstance.sceneSettings.setBackgroundColor(BACKGROUNDS[theme]);
}

// Once for the theme that is already active, then for every later change.
// These two helpers are your own theme code.
applyTheme(currentTheme);
onThemeChange(applyTheme);

Runnable examples: the plain TypeScript project MoorhenWebComponent wires its theme toggle to setBackgroundColor() exactly like this, and the React project MoorhenWebComponentReact does the same from a useEffect.

API tip: centerOnResidue, centerOnAtom and centerOnCoordinate are methods of MoorhenInstance, while the generated sceneSettings setters (a large family including setBackgroundColor, setAmbient, setZoom …) are described on the same API page.
