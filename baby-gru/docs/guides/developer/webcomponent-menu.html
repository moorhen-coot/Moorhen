Extending the Moorhen menu bar

The Moorhen menu bar can be extended at runtime through moorhenInstance.menuSystem, a MoorhenMenuSystem. Adding a menu is two steps: add a main-menu entry, then define the submenu it opens. The API is framework-agnostic, so the same code works in a plain page and in React.

Prerequisite: the examples assume you already hold a moorhenInstance (see Setting up the WebComponent or Using the WebComponent in React). The WebComponent always provides a menu system, so moorhenInstance.menuSystem is set.

Slots: inserting your own HTML into a menu uses a separate mechanism, the HTMLslot item type. See Custom HTML slots.

1. Add a main menu entry

A main-menu entry is a MainMenuType: a sub-menu (opens one of your submenus), a modal, a panel, or a jsx element. The most common is a submenu: 

import type { MainMenuEntrySubMenu } from "moorhen/web-component";

const extraMenu: MainMenuEntrySubMenu = {
    type: "sub-menu",
    label: "Extra",
    ariaLabel: "Extra menu",
    icon: "MatSymDownload",
    menu: "extra-menu",   // the id of the submenu to open
    align: 5,             // ordering hint among the existing menus
};

moorhenInstance.menuSystem?.addMainMenu(extraMenu, 2);
  • menu must match the key you use when defining the submenu below.
  • icon is a MoorhenSVG name (for example "MatSymDownload"). Use iconSrc instead to point at an image URL.
  • The second argument of addMainMenu is the position in the menu bar. Existing entries at or after that position are shifted along; omit it to append the entry at the end.

The other entry types are described on the MainMenuType page:

Type What it does
sub-menu Opens one of your submenus (set menu to its id).
modal Opens a Moorhen modal by modal key, with optional args.
panel Opens one of the side panels by panel id.
jsx Renders your own React element (set component).

2. Define the submenu and its items

Submenus are described with a SubMenuMap and registered with addSubmenu(). Each submenu has a label and a list of items: 

import type { SubMenuMap } from "moorhen/web-component";

const extraMenuItems: SubMenuMap = {
    "extra-menu": {
        label: "Extra",
        items: [
            {
                id: "extra-load-1bxn",
                type: "item",
                label: "Load 1BXN",
                onClick: () => {
                    moorhenInstance.files.loadFiles(
                        "https://www.ebi.ac.uk/pdbe/entry-files/1bxn.cif",
                    );
                },
            },
            { type: "separator" },
            {
                id: "extra-reset-view",
                type: "item",
                label: "Reset view",
                onClick: () => {
                    moorhenInstance.sceneSettings.resetSceneSettings();
                },
            },
        ],
    },
};

moorhenInstance.menuSystem?.addSubmenu(extraMenuItems);

A menu item is a MenuItemType. All items share some common fields (id, label, ariaLabel, keywords, description) and then differ by type:

type Fields What it does
item onClick A normal clickable entry. This is the one you will use most.
separator label? A horizontal separator between groups of items.
subMenu menu Opens another submenu (nesting).
showModal modal, args? Opens a Moorhen modal.
showPanel panel Opens a side panel.
dispatch action Internal onlyDispatches a Redux action.
preferenceSwitch selector, action Internal onlyA toggle bound to a boolean in the store.
customJSX jsx Internal onlyRenders React element inside the menu.
popover content Internal only Shows a popover built from your own React element.
HTMLslot slotName Renders a <slot> that you fill with your own HTML. This is the supported way to add custom content to the menu from the WebComponent. See Custom HTML slots.
Several items are Internal only. They could be used if you decide to use the "react-lib" integration path. The alternative for the webcomponent is to use slots to insert your own React elements into the menu, which is covered in Custom HTML slots.

Item ids must be unique across all submenus. Moorhen logs a warning if two items share an id, which would make deleteItemById() ambiguous.

3. Modify an existing menu

You do not have to create a new menu: you can add items to one of Moorhen’s submenus with addToExistingSubmenu(), or remove your own items with deleteItemById(): 

// Add an item at the bottom of the built-in "file" submenu.
moorhenInstance.menuSystem?.addToExistingSubmenu(
    [
        {
            id: "my-open-custom",
            type: "item",
            label: "Open my structure",
            onClick: () => {
                moorhenInstance.files.loadFiles("/my-structure.pdb");
            },
        },
    ],
    "file",
);

// Remove an item again by its id.
moorhenInstance.menuSystem?.deleteItemById("my-open-custom");

Pass true as the third argument of addToExistingSubmenu() to insert the items at the top of the submenu instead of the bottom.

API reference

  • MoorhenInstance.menuSystem — entry point.
  • MoorhenMenuSystem — addMainMenu(), addSubmenu(), addToExistingSubmenu(), deleteItemById().
  • Configuration types: MainMenuType, MainMenuEntrySubMenu, MenuItemType, SubMenuMap.
