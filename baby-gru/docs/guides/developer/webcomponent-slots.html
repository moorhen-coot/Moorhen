Injecting your own HTML with slots

Slots let you place your own HTML inside Moorhen’s UI. They use the native Web Components slot mechanism: you give an element a slot="<name>" attribute as a child of <moorhen-web-component>, and Moorhen renders a matching <slot name="<name>"> where you asked for it.

Current limitation: for now slots can only be placed in the menu bar, as an HTMLslot menu item. Using slots for custom modals and side panels is planned for a future version.

Why slots? The WebComponent renders its UI in a shadow root, so you cannot inject React elements into its menus directly (that path, customJSX, is reserved for the moorhen/react-lib integration). Slots are the supported way to add your own controls to the menu from the WebComponent.

Prerequisite: the examples assume you already hold a moorhenInstance (see Setting up the WebComponent or Using the WebComponent in React) and that you have read Adding custom menus.

1. Add an HTMLslot menu item

Add an HTMLslot item to one of your submenus. Its slotName is the link between the menu and the HTML you will provide: 

import type { SubMenuMap } from "moorhen/web-component";

const slotMenu: SubMenuMap = {
    "extra-menu": {
        label: "Extra",
        items: [
            {
                id: "extra-controls",
                type: "HTMLslot",
                label: "My controls",     // used by the search bar and for accessibility
                slotName: "my-controls",  // matched by slot="my-controls" in your HTML
            },
        ],
    },
};

moorhenInstance.menuSystem?.addSubmenu(slotMenu);

The submenu structure is the same as in Adding custom menus; the surrounding main-menu entry is unchanged. The HTMLslot item replaces the normal menu entry, so its label is never drawn. It is only used by the search bar and for accessibility; the visible content is entirely the HTML you provide.

2. Provide the content from the host page

Put the content inside the <moorhen-web-component> element and give it the matching slot attribute: 

<moorhen-web-component id="moorhen-1" width="1000" height="800">
    <div slot="my-controls" class="my-controls">
        <button id="do-something">Do something</button>
    </div>
</moorhen-web-component>

Those children are assigned to the <slot name="my-controls"> that Moorhen renders inside the menu, so the button appears in the menu when it is opened. Then wire it up as usual: 

document.getElementById("do-something")?.addEventListener("click", () => {
    moorhenInstance.files.loadFiles("/my-structure.pdb");
});
  • The slotted elements must be children of the <moorhen-web-component> element.
  • They are normal elements in your page’s DOM, so your own CSS applies to them. Moorhen’s styles do not leak in, and yours do not leak out.
  • Any HTML works: buttons, inputs, labels, images, and so on.

3. In React

In a React app, render the slotted content as children of the element. The slot attribute and your handlers work as usual: 

<moorhen-web-component id="my-moorhen" width={1000} height={800}>
    <button
        slot="my-controls"
        onClick={() => moorhenInstanceRef.current?.files.loadFiles(["/my-structure.pdb"])}
    >
        Load my structure
    </button>
</moorhen-web-component>

React renders those children into the light DOM of the custom element, which is exactly what the slot mechanism expects.

Current limitations

  • Slots can only be inserted in the menu bar, as an HTMLslot menu item.
  • Using slots to build custom modals and side panels is planned, but not available yet.

See the MenuItemHTMLSlot type and MenuItemType in the API reference.
